# 智能校园微服务课程选退课系统 部署说明

## 1. 环境要求

| 组件 | 版本要求 | 说明 |
| ---- | ---- | ---- |
| JDK | 17+ | 推荐 Eclipse Temurin 17 |
| Maven | 3.8+ | 构建后端工程 |
| MySQL | 8.0+（兼容 5.7） | 执行 `sql/init_smart_campus.sql` 初始化 |
| Nacos | 2.x | 服务注册与配置中心（本地已安装：`O:\nacos-server-2.3.2`） |
| Sentinel Dashboard | 1.8.x | 可选，用于动态配置限流/熔断规则 |
| Node.js | 18+ | 构建前端 |
| 浏览器 | Chrome / Edge / Firefox 最新版 | 客户端 |

## 2. 数据库初始化

使用您本机的 MySQL root 账号执行：

```bash
mysql -u root -p < sql/init_smart_campus.sql
```

脚本会创建数据库 `smart_campus` 及 7 张表并写入种子数据。
若数据库账号密码不是 root/root，请同步修改各服务
`src/main/resources/application.yml` 与 `application-local.yml` 中的 datasource 配置。

默认账号：

| 角色 | 账号 | 密码 |
| ---- | ---- | ---- |
| 管理员 | admin | Admin123 |
| 教师 | T1001 / T1002 / T1003 | Pass1234 |
| 学生 | 20210001 ~ 20210005 | Pass1234 |

## 2.5 一键启动/停止（推荐）

项目根目录提供了两个脚本（MySQL57 为系统自启动服务，无需手动处理）：

- `一键启动.cmd`：按顺序启动 Nacos → 5 个业务服务 → 网关 → 前端，
  每个环节自动等待端口就绪，全部启动后自动打开浏览器 http://localhost:5173/login；
  各服务在最小化窗口中运行，便于查看日志。
- `一键停止.cmd`：停止前端、网关、各业务服务与 Nacos（MySQL 保留运行）。

> 脚本会自动检测端口是否已占用；若某一步超时失败，请打开对应最小化窗口查看错误日志。

## 3. 两种运行模式

### 3.1 完整微服务模式（推荐，演示 Nacos 服务治理）

1. 启动 Nacos（单机模式）：
   ```bash
   cd O:\nacos-server-2.3.2\nacos\bin
   startup.cmd -m standalone
   ```
   浏览器打开 http://localhost:8848/nacos（默认账号 nacos/nacos）。

2. 启动 5 个业务服务（默认 profile 自动注册到 Nacos）：
   ```bash
   java -jar user-service/target/user-service-1.0.0.jar
   java -jar course-service/target/course-service-1.0.0.jar
   java -jar selection-service/target/selection-service-1.0.0.jar
   java -jar recommend-service/target/recommend-service-1.0.0.jar
   java -jar statistics-service/target/statistics-service-1.0.0.jar
   ```

3. 启动网关：
   ```bash
   java -jar gateway-service/target/gateway-service-1.0.0.jar
   ```

4. 在 Nacos 控制台「服务管理→服务列表」可看到 5 个服务已注册。

### 3.2 本地直连模式（不依赖 Nacos，快速体验）

给每个服务加 `--spring.profiles.active=local` 启动参数即可。
local 档通过 `SimpleDiscoveryClient` 将服务名解析为 localhost 固定端口，
网关也切换为直连路由，无需启动 Nacos：

```bash
java -jar user-service/target/user-service-1.0.0.jar --spring.profiles.active=local
java -jar course-service/target/course-service-1.0.0.jar --spring.profiles.active=local
java -jar selection-service/target/selection-service-1.0.0.jar --spring.profiles.active=local
java -jar recommend-service/target/recommend-service-1.0.0.jar --spring.profiles.active=local
java -jar statistics-service/target/statistics-service-1.0.0.jar --spring.profiles.active=local
java -jar gateway-service/target/gateway-service-1.0.0.jar --spring.profiles.active=local
```

## 4. 前端启动

```bash
cd frontend
npm.cmd install
npm.cmd run dev
```

浏览器访问 http://localhost:5173。
开发服务器将 `/api` 代理到网关 http://localhost:8080。

生产构建：

```bash
npm.cmd run build
```

将 `dist/` 部署到 Nginx，并把 `/api` 反向代理到网关 8080 端口即可。

## 5. 微服务端口规划

| 服务 | 端口 | 说明 |
| ---- | ---- | ---- |
| gateway-service | 8080 | 统一入口 `/api/**`，鉴权、路由、跨域 |
| user-service | 8081 | `/api/user/**` |
| course-service | 8082 | `/api/course/**` |
| selection-service | 8083 | `/api/selection/**` |
| recommend-service | 8084 | `/api/recommend/**` |
| statistics-service | 8085 | `/api/statistics/**` |

## 6. 常见问题

- **无法连接数据库**：检查 `application-local.yml` 中 datasource 的账号密码，
  以及 MySQL 服务（MySQL57）是否已启动。
- **网关返回 401**：Token 过期或未携带 `Authorization: Bearer <token>`；
  前端登录后自动携带。
- **Feign 调用报 UnknownHost / 503**：完整模式下确认 Nacos 已启动且服务已注册；
  本地模式下确认各服务均以 local profile 启动。
- **选课提示不在开放时间**：管理员在「选课参数」页面调整 select_start / select_end。
