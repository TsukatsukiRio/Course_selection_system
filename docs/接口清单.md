# 微服务接口清单

统一响应格式：`{ "code": 200, "message": "success", "data": {} }`
鉴权方式：`Authorization: Bearer <JWT Token>`（网关统一校验）

## user-service（8081）

| 方法 | 路径 | 权限 | 说明 |
| ---- | ---- | ---- | ---- |
| POST | /api/user/auth/register | 公开 | 学生注册 |
| POST | /api/user/auth/login | 公开 | 登录，返回 JWT |
| GET | /api/user/profile | 登录 | 当前用户信息 |
| PUT | /api/user/profile | 登录 | 修改个人资料 |
| PUT | /api/user/profile/password | 登录 | 修改密码 |
| GET | /api/user/notice/list | 登录 | 公告列表 |
| GET | /api/user/admin/page | ADMIN | 用户分页 |
| POST | /api/user/admin | ADMIN | 创建教师/管理员 |
| PUT | /api/user/admin/{id} | ADMIN | 编辑用户/启禁用 |
| PUT | /api/user/admin/{id}/reset-password | ADMIN | 重置密码 |
| POST | /api/user/admin/import | ADMIN | CSV 批量导入学生 |
| GET/POST/PUT/DELETE | /api/user/notice/admin/** | ADMIN | 公告维护 |
| GET | /api/user/internal/** | 内部 | Feign 用户查询 |

## course-service（8082）

| 方法 | 路径 | 权限 | 说明 |
| ---- | ---- | ---- | ---- |
| GET | /api/course/page | 登录 | 组合检索（名称/编号/教师/院系/类型/学分） |
| GET | /api/course/{id} | 登录 | 课程详情+教学计划 |
| GET | /api/course/hot | 公开 | 热门课程 |
| POST/PUT/DELETE | /api/course/admin/** | ADMIN | 课程增删改、状态 |
| GET | /api/course/teacher/mine | TEACHER | 我的课程 |
| PUT | /api/course/teacher/{id} | TEACHER | 编辑本人课程 |
| POST | /api/course/teacher/grade | TEACHER | 录入成绩 |
| GET | /api/course/teacher/grades | TEACHER | 成绩查询 |
| POST | /api/course/teacher/teaching-plan | TEACHER | 提交教学计划 |
| PUT | /api/course/admin/teaching-plan/{id}/audit | ADMIN | 审核教学计划 |
| GET/POST | /api/course/internal/** | 内部 | 名额扣减/恢复、成绩、热度 |

## selection-service（8083）

| POST | /api/selection/drop/{id} | 登录(学生) | 退课 |
| GET | /api/selection/my | 登录 | 我的选课记录 |
| GET | /api/selection/schedule | 登录 | 我的课表 |
| GET | /api/selection/conflict-check | 登录 | 选课预检测 |
| GET | /api/selection/open-status | 登录 | 选课窗口状态 |
| GET/PUT | /api/selection/admin/config | ADMIN | 选课参数配置 |
| GET | /api/selection/admin/records | ADMIN | 选课记录分页 |
| GET | /api/selection/teacher/course/{courseNo}/students | TEACHER | 选课学生名单 |
| GET | /api/selection/internal/** | 内部 | 统计聚合、推荐数据 |
